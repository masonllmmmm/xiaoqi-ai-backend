# 文件批量打包压缩工具

纯前端单文件网页工具：把大量文件（PDF / Word / 图片 / 视频 / 任意格式）装进一个文件夹，打包成 ZIP，下载到本机或直接分享。手机、电脑双端可用，断网也能用。

## 特性

- 不挑文件类型：PDF、Office 文档、图片、视频、压缩包均可打包
- 一次可选几百上千个文件；电脑端可直接拖入整个文件夹（保留目录结构）
- 手机端：文件 App / 相册多选，可多次添加
- 自动建立顶层文件夹，解压后文件不会散落一地
- 智能压缩：检测到几乎都是 PDF / 图片 / 视频等已压缩格式时，自动切「仅打包」，省时省电
- 4 档压缩方式可手动覆盖
- 重名文件自动编号
- 全程本地处理，文件不上传服务器

## 部署到 GitHub Pages

1. 新建 Public 仓库，例如 `zip-tool`
2. 上传 `index.html`、`.nojekyll`
3. Settings → Pages → Source 选 `Deploy from a branch`，分支 `main`，目录 `/ (root)` → Save
4. 等 1～2 分钟，访问 `https://<用户名>.github.io/zip-tool/`

仓库需为 Public 才有免费 Pages；Pages 自带 HTTPS，手机的「分享」功能才能调用。

## 手机怎么用

- **iPhone**：「选择文件」→「浏览」进文件 App 多选 PDF / 文档；「照片图库」多选照片视频
- **Android**：「选择文件」进文件管理器，长按多选
- 打包完优先用「分享」发微信或存到「文件」App；「下载」会存到「下载」目录
- 手机不支持拖拽和选择整个文件夹，这两个按钮会自动隐藏

## 说明

- 上限受设备内存限制，手机一般 1GB 以内没问题
- 国内访问 github.io 可能较慢，备选：Vercel / Netlify / Cloudflare Pages，同样是上传文件即可
